### **Project Overview**

**NSSH** (*Not Secure SHell*) is a **deliberately insecure** version of SSH, since I'm the one who built the **cryptographic building blocks** used to set up the **encrypted tunnel**.

Other than that, it was **super fun** to build! This project let me:
- Learn **Rust**.
- Implement **AES and RSA** as covered in class.
- For fun, I also implemented **SHA-256** from [a spec](https://csrc.nist.gov/files/pubs/fips/180-2/final/docs/fips180-2.pdf).
- Redo some **TCP sockets** to simulate my SSH connection.

Anyway, lots of fun stuff for a **great project** *(America won't get my data!)*.
